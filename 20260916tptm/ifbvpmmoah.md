# 缺关键物资、有破局良方！中国军医创新方案开展埃军高技术医院首例开胸术

> 更新时间：2026-09-16 (UTC+8)

“右肺纤维化组织完全切除，气道压力恢复正常，可以关胸！”随着中国第11批援埃塞俄比亚军医专家组胸外科主治医师李昆的指令，埃军高技术医院首例开胸手术宣告成功。

**病情危急**

✓

贯穿伤三月未愈，肺功能严重受损

5月，阿沃尔因右侧胸壁贯穿伤转诊至埃军高技术医院，被诊断为右侧胸部贯穿伤、右侧血气胸。经过2个月药物治疗和4次胸腔闭式引流，病情仍未好转，右肺持续塌陷，大量胸腔积液积气伴纵膈左移，患者出现呼吸困难、体重锐减等症状，肺功能严重受损，生命垂危。

**精准施策**

✓

改良引流显成效，远程会诊定方案

李昆医生接诊后，精准判断前期引流效果不佳是引流管位置不当引起的。他立即将引流管改置于右侧锁骨中线第2肋间，当日便引流出约1000毫升脓性胸腔积液。复查CT显示右肺部分复张，纵膈位置改善。但长时间感染导致脓液积聚严重，仅靠引流无法恢复肺功能。

经与西南医院胸外科专家远程会诊，专家们一致建议立即进行开胸探查及清创。然而，当地医院没编设胸外科、缺乏相关经验与器械，且保障术中单肺通气的双腔气管导管等医疗物资暂未送达，手术面临诸多难题。

在军医专家组队长郭浩的带领下，专家组多次讨论，并与西南医院麻醉科专家磋商，创新制定手术保障方案：无双腔气管导管，就用单腔气管导管在纤维支气管镜辅助下插入对侧主气道通气；无胸外科器械，就用普外科器械替代。

**精心筹备**

✓

设备保障筑防线，协作带教促成长

“埃军高技术医院的纤维支气管镜从未启用，能否助力手术尚且存疑。”在讨论后，军医专家组张诗慧工程师提前进入设备间，对电子支气管镜和全自动内镜清洗机进行安装、校准与反复检测，确保设备性能稳定，还对电子支气管镜严格清洗消毒，保障设备无故障、镜体无菌、成像清晰。

当地医生Abay曾赴西南医院进修，此次与张诗慧并肩工作。张诗慧不仅亲自示范调试、清洗、检测步骤，还结合临床经验讲解术中可能出现的复杂情况并指导操作，帮助Abay巩固技能、积累经验，也推动当地医院建立规范的设备管理与感染控制流程，为其独立开展高风险外科手术奠定基础。

**攻坚克难**

✓

协作完成手术，患者重获新生

在与医院各级部门密切协调后，手术如期启动。郭浩队长与手术室Beka麻醉医师团队紧密协同，顺利完成该院第一例电子纤维支气管镜辅助下左主支气管插管，实现左侧单肺通气，并在后续手术中持续监测二氧化碳分压、气道压力等指标。

手术由李昆医生主刀，当地外科医生Dr.Biniyam担任助手，这是Dr.Biniyam首次参与开胸手术。术前，李昆耐心为其讲解手术方案和操作要点；术中，手把手指导每一个关键步骤，让其在实战中学习成长。

术中，困难挑战重重，患者右侧胸腔严重粘连，胸膜及肺表面覆盖厚厚的纤维板，还残留大量脓性分泌物，且当地电刀老旧、无长刀头，器械短缺，操作难度极大，这就需要考验医生的技术和团队的协作。在中埃医生的默契配合下，经过2.5小时的紧张奋战，成功为患者完成胸腔清创及右侧膈肌破裂修补。术后第一天，CT复查显示患者右肺明显复张，呼吸功能显著改善，阿沃尔露出了久违的笑容。

第11批援埃塞俄比亚军医专家组自5月抵达以来，用行动诠释了红色军医的担当，以长效帮扶为导向 ，通过远程指导、联合手术等多元模式赋能当地，精准帮带急诊、妇产等科室提升诊疗能力，还将中医智慧带到非洲，以百余人次的针灸、针刀治疗，让传统医学成为服务当地的新力量。
